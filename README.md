### 💼 Proyectos Destacados

#### 💈 [BarberPro](https://github.com/MyBarberStore)
Ecosistema integral multi-cliente para la gestión y digitalización de barberías y negocios de citas:
* **Backend:** API RESTful Stateless con Spring Boot 3, autenticación JWT, cálculo dinámico de disponibilidad y generación de facturación PDF.
* **Frontend Web:** Panel de administración reactivo desarrollado con Angular 17+ y Signals.
* **Mobile App:** Aplicación nativa Android desarrollada en Kotlin (MVVM, Coroutines, Retrofit y mapas interactivos).
